# BLACKLINE MOToring

A cinematic luxury automotive dealership portfolio project built with React + Vite.

## Run

```bash
npm install
npm run dev
```

Then open the local Vite URL.

## Included interactions

- Cinematic hero image transition by changing selected vehicle
- Scroll reveal animations
- Infinite marquee
- Interactive vehicle collection switcher
- Hover image scaling and magnetic-feeling CTA interactions
- Responsive mobile navigation
- Private viewing booking modal with form state
- Reduced-motion accessibility support

## Note

Demo photography is loaded from Unsplash/Pexels URLs for the portfolio prototype. Replace image URLs with licensed/client assets before production use.
